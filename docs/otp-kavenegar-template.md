# قالب پیشنهادی پیامک OTP در کاوه‌نگار (برای Autofill آیفون + اندروید)

نام قالب فعلی در کد: `otp-login`  
متغیر کاوه‌نگار: `%token` = کد ۴ رقمی

## متن پیشنهادی قالب (کپی در پنل کاوه‌نگار)

```text
Code: %token
کد ورود اپال‌باکس: %token
@opalbox.ir #%token
```

## چرا این فرمت؟

نمونه‌هایی که روی آیفون خوب کار می‌کنند معمولاً این‌ها را دارند:

1. خط انگلیسی `Code: 1234` → پیشنهاد بالای کیبورد (QuickType) در Safari/Chrome
2. خط دامنه `@opalbox.ir #1234` → اتصال امن کد به سایت (iOS 14+)
3. کد به‌صورت جدا، نه فقط داخل جملهٔ فارسی بلند

قالب قبلی شبیه این بود و روی آیفون ضعیف عمل می‌کرد:

```text
به فروشگاه اپال باکس خوش آمدید... کد ورود شما: 3848
@opalbox.ir #3848
```

(کد داخل متن فارسی است و `Code:` انگلیسی ندارد.)

## نکات

- دامنه باید دقیقاً همان host سایت باشد: `opalbox.ir` (بدون www مگر سایت با www باز شود)
- اگر سایت را با `www.opalbox.ir` باز می‌کنید، یا ریدایرکت به بدون www بگذارید یا در SMS همان www را بنویسید
- بعد از تغییر قالب در کاوه‌نگار، یک OTP جدید بفرستید و در Safari و Chrome آیفون تست کنید
- «لغو11» اگر کاوه‌نگار ته پیام اضافه می‌کند معمولاً مشکلی نیست؛ مهم خطوط بالا هستند

## تست سریع بعد از تغییر

1. آیفون Safari → صفحه ورود → درخواست کد
2. پیامک را چک کنید که سه خط بالا را دارد
3. فیلد OTP را فوکوس کنید → باید پیشنهاد کد بالای کیبورد بیاید
4. همان تست در Chrome iOS

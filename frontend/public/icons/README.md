# PWA Icons

این پوشه باید شامل icon های زیر باشد:

- `web-app-manifest-192x192.png` (192x192 pixels) - **ضروری** ✅ موجود است
- `web-app-manifest-512x512.png` (512x512 pixels) - **ضروری** ✅ موجود است

## نکات مهم:

1. Icon ها باید با فرمت PNG باشند
2. Icon اصلی باید شامل لوگوی "G" یا "گلد تریدر" باشد
3. رنگ پس‌زمینه: طلایی (#D4AF37) یا سفید
4. برای تولید icon ها می‌توانید از ابزارهای آنلاین استفاده کنید:
   - https://realfavicongenerator.net/
   - https://www.pwabuilder.com/imageGenerator
